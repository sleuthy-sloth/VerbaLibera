# VerbaLibera B2–C2 Roadmap Plan

> **For Hermes:** implement phase-by-phase with TDD per task (write failing test → minimal impl → lint/typecheck/build → commit). Each phase is independently shippable.

**Goal:** Grow VerbaLibera from A1 travel drills into an app that can carry a learner to B2 (and lay honest track toward C1/C2) through new learning modes — without breaking the local-first, no-LLM-judge architecture.

**Architecture:** New drill kinds ride the existing pipeline (Prisma `DrillKind` enum + migration → fixture seeds → `resolveSessionContent` → step UI → composer order). Curriculum stays data-driven (`fixture.ts` + `docs/content-authoring.md` + provenance scripts). Open production is assessed by constraint, not by AI judge, until/unless an optional judge is explicitly chosen.

**Tech Stack:** Next.js 16 / React 19 / TS / Prisma+Postgres / Kokoro TTS + faster-whisper STT sidecar (unchanged).

---

## Honest constraints (read first)

1. **No LLM judge in the stack.** B2+ free writing/speaking cannot be graded locally. All open-production modes below are designed checkable-by-constraint (exact variants, slot validation, error-spotting keys, self-assessment rubrics) or human-in-the-loop (record-and-compare, export to tutor/Anki).
2. **Content is the bottleneck, not code.** 32 A1 patterns → B2 needs ~150–250 patterns + ~2,000–4,000 vocab items across 4 languages. Authoring throughput (fixture + WAVs + provenance + STT screen + listen) is the schedule driver. The plan front-loads authoring tooling.
3. **CEFR claims must be mapped, not marketed.** Never label content B1/B2 until a `cefr` field + coverage checklist exists (Phase 1). The app earns each level publicly.

## Phase 4 — Productive skills without a judge

`SHADOWING` (waveform compare, labeled rhythm-not-grading), `GUIDED_WRITING` (rubric self-assessment, exportable), `CONVERSATION_SIM` (authored branching dialogues). Practice, never auto-assessment.

## Phase 5 — B2 core (content-led; one architectural fork)

Subjunctive, conditionals, passive, reported speech, register, argumentation. Optional `LLM_JUDGE` behind explicit opt-in + BYO key — spec'd but NOT built until chosen.

## Phase 6 — C1/C2 track (fog — specify after B2 lands)

Idiom banks, nuance discrimination, long-form listening, stylistic rewriting, extensive reading. C2 open-production auto-grading out of scope by design.
