# Asset provenance

Every asset in this document is an original VerbaLibera project asset. They were
generated with the built-in image-generation tool, visually inspected before being
placed in `public/`, and have no third-party source material, logos, mascots, or
embedded text. The generation prompts for the Warm Studio set are in
[`docs/design/graphics-brief.md`](design/graphics-brief.md); this file records what
shipped, where it came from, and what the brand tooling changed.

The picture-choice vocabulary photographs are separate and are documented in
[`docs/image-provenance.md`](image-provenance.md) (CC0 / public domain from
Wikimedia Commons, licence checked per file).

## Approved references, and what the tree does with them

The generated originals (the approved references, dated 2026-09-10) live outside
the repository in `~/Downloads`. `scripts/brand/compare-reference.py` compares
each shipped file against its reference by searching for the horizontal shift that
minimises the grey difference, which tells three cases apart: the same picture
re-encoded (shift 0, tiny residual), the same picture moved inside the frame (a
non-zero shift that clearly beats shift 0), and a different picture.

```bash
python3 scripts/brand/compare-reference.py --crops
```

| Shipped | Reference | Difference at rest | Best shift | Verdict |
| --- | --- | ---: | ---: | --- |
| `courses/french.jpg` | Course Banner French | 1.09 | 0 px | the reference, re-encoded |
| `courses/italian.jpg` | Course Banner Italian | 1.68 | 0 px | the reference, re-encoded |
| `courses/spanish.jpg` | Course Banner Spanish | 1.42 | 0 px | the reference, re-encoded |
| `courses/portuguese.jpg` | Course Banner Portugal | 1.36 | 0 px | the reference, re-encoded |
| `courses/german.jpg` | Course Banner German | 1.54 | 0 px | the reference, ground snapped to the canvas |
| `hero-banner.jpg` | Hero Banner | 25.77 | −31 px | re-framed (`tighten-frame.py`) |
| `empty-journal.jpg` | Empty Journal | 25.51 | −14 px | re-framed (`tighten-frame.py`) |
| `logo-mark.jpg` | Logo Mark | 31.04 | 0 px | re-framed and rescaled (`tighten-frame.py`) |
| `logo-lockup.jpg` | Logo Lockup | 4.71 | 0 px | the reference, re-encoded |
| `og-card.jpg` | Social Card | 28.32 | 0 px | cropped to the specified 1200×630 (reference is 1376×768) |

The remaining re-frames are deliberate and documented in
`docs/design/graphics-brief.md`: `tighten-frame.py` centres the drawing inside a
crop of the *same* aspect ratio so no declared dimension had to change.

**The German banner is no longer one of them.** It shipped re-framed — the
approved artwork moved +278 px inside its frame, which is what the earlier
measurement of this table recorded as "71.10 at rest, best shift +278 px" — and it
now **is** the approved reference, with its ground snapped to the canvas
(`scripts/brand/snap-ground.py`, which is also what keeps the flat cream field
from reading as a faint rectangle against the page). The history is worth keeping
because the re-frame was not arbitrary: the approved scene runs off the right edge
through a distinct building, and the brief's column analysis (the complete scene
ends at x≈1890, a different building starts at x≈1899) is why the re-frame
centred it instead. That trade-off has now been reverted deliberately, artwork
preserved exactly as approved.

**Its measured consequence** (`--crops`): the approved framing needs a
narrow-viewport window of aspect **2.75 anchored at 100%** — the window sits at the
frame's right edge, which is where the drawing runs to — against **2.39 at 50.4%**
for the re-framed file that used to ship. Both windows keep the whole drawing
(`tests/banner-crops.test.ts` re-derives that from the pixels), and the crop is
re-measured by `python3 scripts/brand/banner-crops.py`, which is the only step
needed if the file is ever swapped again.

The picture drill's vocabulary pictures have their own record in
`docs/image-provenance.md`, which now also covers the four that were replaced with
the project's own approved illustrations.

## Icons

`public/icons/verbalibera-maskable-512.png` is declared `purpose: "maskable"` in
`src/app/manifest.ts`, so Android may crop it to any launcher shape: the
guaranteed-visible region is the central circle of 80% of the width.
`scripts/brand/icon-audit.py` measures it:

| Icon | Drawn area (% of frame) | Safe zone | vs the approved icon |
| --- | --- | --- | --- |
| `verbalibera-maskable-512.png` | x 26–74%, y 32–68% | **inside** | re-composited, inset (as intended) |
| `verbalibera-512.png` | x 16–83%, y 25–75% | not required | 5.9 mean grey difference |
| `verbalibera-192.png` | x 16–83%, y 25–74% | not required | 7.7 |
| `apple-touch-icon.png` | x 16–83%, y 25–74% | not required | 8.1 |

The drawing reaching past that circle on the non-maskable icons is correct: those
are shown as they are. The maskable one is inset, which is why it differs most
from the approved square — that difference *is* the safe zone.

## Removed files, and what replaced them

Three files this document used to describe are gone. They are recorded here — with
the prompts that produced them — so the history is not a mystery, and so nothing
quietly re-adds them.

**`public/brand/verbalibera-app-icon-source.png`** (1254×1254) — removed when Warm
Studio replaced the Signal Pop palette (coral, lime, indigo) it was drawn for. The
icon set that replaced it is the approved `App Icon.jpeg` in `~/Downloads`, and
`scripts/brand/icon-audit.py` checks that every shipped icon still matches it.

```text
Use case: logo-brand
Asset type: PWA app-icon source and dashboard visual system
Primary request: an original abstract speech-wave emblem for VerbaLibera: a coral curved speech wave and a small lime motion accent inside a rounded indigo square, clean high-contrast silhouette, friendly but adult, premium mobile-app icon
Style/medium: polished contemporary raster illustration, simple geometric forms
Color palette: Ink #20233D, Indigo #7068FF, Coral #FF765F, Lime #B8F266, Cloud #F8F7FF
Constraints: no text, no letters, no faces, no animals, no brand resemblance, no watermark, preserve a large safe margin around the symbol
```

**`public/brand/voxlibre-app-icon-source.png`** (999,158 B) — a VoxLibre file that
had been sitting in this project's brand directory, referenced by nothing. Removed
in the 2026-09-10 graphics pass; sha256
`e59b88313a3f5245f6ac446afc7eba4fed7481f4046e697663af392782567e9f`, recoverable
with `git show 5d8ff79:public/brand/voxlibre-app-icon-source.png`.
`tests/image-dimensions.test.ts` now fails if an unreferenced file reappears in
`public/brand`.

**`public/illustrations/daily-practice.png`** (1536×1024) — removed with the
dashboard it was drawn for. The dashboard now uses `hero-banner.jpg`, and the
first-run onboarding uses `logo-lockup.jpg` plus `empty-journal.jpg`; all three
carry empty alternative text because the adjacent copy is what means something.
