# VerbaLibera v0.3.0

This release is a full pass over how the app looks, reads, and sounds. The interface has a new identity, the lessons stopped talking like a grader, and every listening track is now long enough for a walk.

## New visual identity

The app moves to Warm Studio: cream stock, one terracotta accent, Fraunces for display and Instrument Sans for text. Depth is a hard offset shadow on flat shapes, so there is no blur, no glass, and no gradient anywhere in the interface.

This replaced two earlier directions (Quiet Ink, and Liquid Glass before it) and, more importantly, it replaced the drift between them. Six palettes had accumulated across the shell, the two lesson engines, the landing page, and the welcome flow. They are now one system, enforced by `tests/design-tokens.test.ts`.

New graphics across the board: logo mark and lockup, an app icon set, a social card, and illustrated course banners for all five languages. German is new; the banner and the listening track are both wired into the catalogue.

`DESIGN.md` documents the tokens.

## Lessons that no longer sound like a grader

The lesson engine was printing its own internal vocabulary at learners. An answer came back labelled `correct`, or "That matches an authored answer", and the same panel rendered for both a right and a wrong answer.

Learner-facing wording now lives in one module (`features/course-pack/feedback.ts`). Acknowledgements rotate instead of repeating, right and wrong carry different states, and the internal category survives only as a data attribute. The specific diagnostic copy for a real miss was kept, because it was already good.

## Listening

Every track was expanded to 10 to 13 minutes in Language Transfer style, teaching several things in sequence rather than one:

- French: Names and introductions (10:17)
- Italian: At the market (11:03)
- German: Introductions and a first café visit (12:40)
- Portuguese: Introductions and a first café visit (12:45)
- Spanish: Introductions and a first café visit (12:52)

The audio player now shows a real duration instead of `0:00 / 0:00`, and tracks can be saved as MP3s for offline listening.

## Getting there

Navigation and legibility pass across the whole learner surface: a desktop header instead of a mobile capsule stretched wide, WCAG AA contrast on every route at both viewports, honest 404s for retired URLs, and a profile that leads with what you can actually say rather than a streak. The first-run welcome flow moved onto the design system.

The offline fallback page and the installed app's theme colour now match the rest of the app, and both were wrong through the previous release.

## Tooling

- `npm run shots` regenerates the README screenshots from a running dev server.
- `npm run a11y:audit` checks every learner route at desktop and mobile. It now fails when routes error, rather than reporting success for an audit that never ran, and it reports how many contrast checks axe could not decide.
- `scripts/brand/` handles generated art: installing at the right geometry, and snapping the ground colour to the exact canvas value.

## Testing

827 unit tests, 62 browser tests, and zero axe violations across 20 route and viewport combinations.

## Still open

Foundation lessons remain machine-authored and consistency-checked. Native-speaker editorial review is not done, and the audio player says so on every track. Placement is a rough starting suggestion, not a CEFR certification. Physical iPhone testing (Add to Home Screen, offline relaunch, background and foreground) is still outstanding.

The 32 vocabulary images are still photographs, which is the largest remaining mismatch with the illustration system.
