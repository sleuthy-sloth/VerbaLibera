# VerbaLibera v0.3.1

The desktop app builds for the first time, and the grader stops marking people wrong for typing.

## The macOS build works

Every tagged release before this one failed in the same place. The release workflow sets a test flag for the whole job, which activates a PostgreSQL test on the first test run, but the database runtime was not staged until fourteen steps later. No tag had ever produced an installer. v0.1.0, v0.2.0 and v0.3.0 all died there.

Staging the database runtime before the tests cleared that, and exposed the real blocker underneath: the Electron package ships no postinstall script, so a clean machine installs it without its binary and every desktop test fails to launch (`ENOENT`). It was always present on a development machine, which is why nobody saw it.

Both are fixed, and the pipeline now runs end to end: it packages a 430 MB `VerbaLibera-mac-arm64.dmg` (arm64, 1.97 GB installed) and a 16 MB single file portable edition, each with a SHA-256 checksum. The disk image mounts, contains the app bundle with the drag-to-Applications layout, and detaches cleanly.

The app inside reports `com.electron.verbalibera`, which is Electron's default identifier rather than a branded one. That is cosmetic for an unsigned build and should be changed before any signed release.

## Grading that forgives

The grader had the machinery to be lenient and it was switched off. All 272 exercises relied on a setting whose default was disabled, so the tolerance path had never once run, and an answer that was right except for a missing accent was marked wrong even though the app knew exactly what was wrong. Writing `J'ai un frere.` failed on a diacritic.

A missing accent and a single slipped letter are now both accepted, the correct form is shown back, and the attempt reports partial credit rather than a bare pass or fail. Every learner-facing line still comes from `features/course-pack/feedback.ts`: an accepted-with-a-fix answer leads with the meaning the learner already had, then names what to fix.

Four things are still not forgiven, and tests pin each one:

- An accent that is the whole word. Italian `e` (and) and `è` (is), French `a` (has) and `à` (to), `ou` (or) and `où` (where), `la` and `là` (there). Accepting these would teach the wrong word, so the learner gets the accent diagnostic without the credit.
- A missing, added or reordered word.
- A misspelling beyond one edit.
- A misspelling that spans two words.

An exercise that is testing spelling itself can still opt out and be strict.

## Graphics

The German course banner was re-framed. It ran off the right edge through a half-timbered house, which read as a sliced building rather than a scene continuing past the frame. The buildings and the tree are now completely contained, and the empty area on the left dropped from 36% to 22%.

German was also missing from all three flag maps, so it alone showed a globe where the other four courses showed a flag. Fixed, and the test that had recorded the omission as correct behaviour now asserts the flag.

Three graphics that sat loosely in their frames were tightened to use their space: the empty journal, the dashboard hero, and the logo mark.

The banner prompts no longer reserve a quiet left third. Nothing has ever been placed there, and measurement showed the art does not leave a third free anyway, so the reservation only cost composition.

## More to learn, and less of the same thing

German, Spanish and Portuguese each went from four lessons to eight, across two
new units. Every new lesson has a shape no other lesson in its course uses, and
they introduce `transform` ("Change the pattern"), an exercise kind that existed
in the schema and was used by none of the 272 exercises: the learner changes a
sentence rather than translating it, which is a different way of thinking about
the language.

The old lessons were repeating themselves more than they looked. Nearly nine in
ten French lessons shared one identical sequence of exercise types, and all eight
topics that the three smaller courses had in common were the same lesson wearing
three language badges. Measured across every pair, they shared 74 to 96% of their
English text and an identical exercise shape, down to answers that were the same
string in every pack: "Hello.", "Thank you.", "Three times.".

Every one of those pairs now sits between 32 and 51%, and no two of the three
languages share a kind sequence. Each language teaches what is genuinely awkward
or surprising for it, so German's first lesson is about greetings that follow the
clock and nouns that wear capitals, Spanish's is about a question mark that opens
before you have read a word, and Portuguese's is about thanks that changes shape
depending on who is speaking. `scripts/content/cross-language-similarity.py`
measures it and `scripts/content/lessons/README.md` documents how it was done.

## Motion

The interface moves like paper, because that is what its depth is made of. A
control lifts off the page when you reach for it and settles flat when you press
it, the verdict note stamps into place, and course cards and track rows lift on
hover and on keyboard focus. It is all short, and it all switches off when the
system or the profile asks for reduced motion.

## Testing

862 unit tests, 62 browser tests, zero axe violations across 20 route and viewport
combinations.

## Still open

The French and Italian courses still teach a repeated shape: 22 of the 25 French
lessons use the same sequence of exercise types. That is the same problem as the
one fixed above, and it is now measured and has a tool for it, but the two large
courses have not been through it.

Foundation lessons remain machine-authored and consistency-checked. Native-speaker editorial review is not done, and the audio player says so on every track. Placement is a rough starting suggestion, not a CEFR certification. Physical iPhone testing (Add to Home Screen, offline relaunch, background and foreground) is still outstanding.

The 32 vocabulary images are still photographs, which is the largest remaining mismatch with the illustration system.
